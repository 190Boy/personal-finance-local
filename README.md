# 現金記帳（personal-finance-local）

只做一件事：記現金。每一筆先存在手機上，連上 Google 後自動同步到你自己雲端硬碟裡的「現金記帳」試算表。銀行、信用卡、股票這類可以匯出檔案的資料不在這裡處理，交給 BOT 定期整理。

- 網址：<https://190boy.github.io/personal-finance-local/web/>
- 目前版本：v1.0.0。各版本改了什麼見 [CHANGELOG.md](CHANGELOG.md)。
- 先前的完整版（銀行、信用卡、股票、雲端發票、LINE Pay、報表）保存在 `backup/full-v0.16.1` 分支。

## 怎麼用

1. **第一次開啟**：按「連接 Google」。網站會在你的雲端硬碟建立「現金記帳」試算表，接著問你身上有多少現金，這個金額記成當天 00:00 的現金。
2. **記一筆**：按下方的 ＋。類型有四種：
   - **支出**、**收入**：選分類（餐飲、交通…／薪資、其他收入…），填金額。
   - **提款**：從銀行領出現金。現金增加，但不算收入。
   - **存入**：把現金存回銀行。現金減少，但不算支出。
3. **修改或刪除**：在首頁點那一筆。
4. **同步**：右上角顯示同步狀態。沒網路或 Google 授權過期（約一小時）時，記帳會先存在手機，標示「N 筆待同步」；點一下重新連接就會補上。

### 現金怎麼算

設定的金額代表「設定當天 00:00 身上的現金」。當天（含）以後的記帳往後加減；設定日以前的記帳則從這個時間點往回推，所以補記以前的帳也會算出當時的餘額。要重設，到「設定 → 目前現金」，一律以今天 00:00 為準。

## 給 BOT 讀的試算表

檔名「現金記帳」，網站自己建立（權限只有 `drive.file`，網站看不到你雲端硬碟裡的其他檔案）。每次同步都會整份重寫前三張表，所以讀到的永遠是最新狀態。

| 工作表 | 內容 |
|---|---|
| 記帳明細 | 一列一筆、依時間排序。欄位：日期、時間、類型（支出／收入／提款／存入）、金額（元）、現金增減（元，支出與存入為負）、主分類、子分類、對象／商店、備註、記帳後現金（元）、ID、更新時間。**BOT 讀這張就好。** |
| 月份統計 | 每月的支出、收入、提款、存入、筆數、月底現金。 |
| 設定 | 起始現金與日期、目前現金、同步時間。 |
| 異動紀錄 | 每次新增、修改、刪除各一列，只增不改，用來在多台裝置之間合併。請勿手動編輯。 |

整理時要注意：**提款、存入是現金和銀行之間的移動**。BOT 合併銀行明細時，銀行端的 ATM 提款和這裡的「提款」是同一筆錢，不要算成兩次支出或收入。

## 資料與隱私

- 記帳存在這台裝置的瀏覽器儲存空間，以及你自己的 Google 試算表；沒有其他伺服器。
- Google 授權 Token 只放在記憶體，不寫入裝置。
- 「設定 → 這台裝置 → 清除」只刪手機上的資料，不影響試算表。

## 開發

```sh
npm test          # 單元測試（含模擬 Google 的兩台裝置同步）
npm run build:pwa # 更新 sw.js 的離線檔案清單
npm start         # 本機預覽 http://127.0.0.1:4173/web/
```

程式結構：

- `cloud/cash.mjs`：記帳、餘額、合併與試算表欄位（純邏輯，不碰網路）
- `cloud/cash-local.mjs`：手機上的記帳與待同步清單
- `cloud/cash-store.mjs`：建立／尋找試算表與同步
- `cloud/auth.mjs`：Google 登入
- `web/app.mjs`：畫面
