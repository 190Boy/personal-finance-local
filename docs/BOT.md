# BOT 說明書：讀取「現金記帳」試算表

> 對應資料格式版本：**2**（網站 v1.1.0 起）
> 最後更新：2026-11-13

這份說明書寫給定期整理 Andy 帳務的 BOT。網站只負責讓 Andy 手動記帳，並把記帳同步到他雲端硬碟裡的試算表；銀行、信用卡、股票等匯出檔由 BOT 處理。BOT 的工作是讀這份試算表，並和那些匯出檔合併、比對、整理。

## 0. 開始前先檢查

1. **找到檔案。** 預設檔名是「現金記帳」，是一份 Google 試算表，但 Andy 可能改過名稱或搬過資料夾。找不到、或找到不只一份時，請 Andy 提供檔案 ID 或網址，不要自己猜。不要讀檔名相似的副本：副本不會再被網站更新。
2. **核對資料格式版本。** 讀「設定」工作表裡「資料格式版本」那一列：
   - 等於本說明書標示的版本：照本說明書處理。
   - 比本說明書新：先停下來，告訴 Andy「說明書需要更新」，不要猜新欄位的意思。
   - 沒有這一列：是格式版本 1（網站 v1.0.0），沒有「渠道」欄，所有記帳都視為現金。
3. **用欄名找欄位，不要寫死第幾欄。** 每張表的第一列都是欄名。
4. **只讀不寫。** 網站每次同步都會整份重寫「記帳明細」「月份統計」「設定」「選項」，BOT 寫進去的東西會被蓋掉。「異動紀錄」被改動還可能讓網站讀不了。整理結果請放在別的檔案。

## 1. 工作表一覽

| 工作表 | 用途 | BOT 要不要讀 |
|---|---|---|
| 記帳明細 | 每筆記帳的最新狀態，一列一筆 | **主要資料來源** |
| 月份統計 | 每月、每個渠道的合計 | 可以拿來驗算 |
| 設定 | 起始現金、目前現金、資料格式版本 | 讀版本與目前現金 |
| 選項 | Andy 自己新增的渠道、分類 | 需要完整分類清單時再讀 |
| 異動紀錄 | 每次新增、修改、刪除各一列（網站內部用） | 通常不用讀 |

## 2. 記帳明細（主要資料）

已刪除的記帳不會出現在這張表；同一筆修改過，也只會出現最新的版本。列的順序依日期、時間、建立時間由舊到新。

| 欄名 | 型態 | 說明 |
|---|---|---|
| 日期 | 文字 `YYYY-MM-DD` | 台灣時間的日期 |
| 時間 | 文字 `HH:MM` 或空白 | 大多數記帳沒有填時間 |
| 類型 | `支出`／`收入`／`提款`／`存入` | 見第 3 節 |
| 渠道 | 文字 | 錢從哪裡付、或進到哪裡，見第 4 節 |
| 金額（元） | 正數，最多兩位小數 | 一律是正的 |
| 增減（元） | 有正負的數字 | 支出、存入為負；收入、提款為正 |
| 主分類 | 文字或空白 | 提款、存入沒有分類 |
| 子分類 | 文字或空白 | 沒選子分類時空白 |
| 對象／商店 | 文字或空白 | 提款、存入時這欄是銀行或帳戶名稱 |
| 備註 | 文字或空白 | |
| 記帳後現金（元） | 數字或空白 | **只有渠道是「現金」的列才有值**，是記完這筆之後身上的現金 |
| ID | 文字 | 每筆記帳唯一、不會變。用來辨識同一筆，修改後 ID 不變 |
| 更新時間 | ISO 8601（UTC） | 最後修改時間 |

## 3. 類型的意義

| 類型 | 現金 | 算支出／收入嗎 | 對應到銀行明細 |
|---|---|---|---|
| 支出 | 渠道是現金時減少 | 是，算支出 | 渠道是銀行或信用卡時，銀行或信用卡匯出檔裡應該有同一筆 |
| 收入 | 渠道是現金時增加 | 是，算收入 | 同上 |
| 提款 | 增加 | **否**，是銀行到現金的移動 | 銀行明細裡的 ATM 提款，**是同一筆錢** |
| 存入 | 減少 | **否**，是現金到銀行的移動 | 銀行明細裡的現金存款，**是同一筆錢** |

提款、存入的渠道一定是「現金」。

## 4. 渠道的意義

- **現金**：Andy 手上的現金。這是唯一完全靠手動記帳的資料，也是這份試算表存在的主要原因。現金的支出、收入沒有其他來源可以核對，以這份試算表為準。
- **銀行、信用卡、LINE Pay**，以及 Andy 自己新增的渠道（例如「悠遊卡」「玉山銀行」）：這些記帳**不是正式帳**，是 Andy 怕看不懂銀行、信用卡匯出檔上的寫法，自己記一筆當作參考，方便比對金額。
  - 和匯出檔比對成功時：**以匯出檔為準，這筆手動記帳不要再算一次**。但可以用它的分類、對象、備註，幫匯出檔那筆加上說明。
  - 找不到對應的匯出紀錄時：列進「待確認」清單給 Andy，不要直接當成支出或收入。可能是匯出檔還沒下載、還沒入帳，或 Andy 記錯。
- 渠道名稱是 Andy 自由填的，不一定和銀行名稱完全一樣。「銀行」「信用卡」是通稱，不會指出是哪一家。

## 5. 和匯出檔比對的建議做法

1. **只比對非現金的列。** 現金的列直接併入總帳。
2. **金額要完全相同。** 用「金額（元）」比對匯出檔的交易金額，方向也要一致（支出對支出、收入對收入）。
3. **日期給一點彈性。** 信用卡入帳日常比消費日晚 1～3 天，以記帳日期往後 3 天內為準。
4. **一對一配對。** 同一筆匯出紀錄只能配給一筆手動記帳。同金額有多筆可以配時，選日期最接近的；仍然分不出來就列為待確認。
5. **提款、存入**：和銀行明細的 ATM 提款、現金存款配對（同金額、同日或隔日）。配對成功表示同一筆錢，總帳裡只算一次「現金與銀行之間的移動」，不算支出也不算收入。
6. **台灣常見的小差額**：例如超商塑膠袋 1～5 元，可能讓金額差一點點。不要自動配對，列成「可能是同一筆」給 Andy 確認。

## 6. 現金餘額

- 「設定」的「起始現金（元）」和「起始日期」：Andy 在起始日期當天 00:00 數過錢包的金額。
- 「目前現金（元）」等於起始現金加上起始日期（含）之後所有現金記帳的增減。這是網站最後一次同步時算的值；「同步時間」是那個時間點（UTC）。
- 起始日期之前的現金記帳，網站會從起始金額往回推算。所以「記帳後現金」在起始日期之前也有值，那是推算出來的。
- 自己驗算時：把渠道是現金、日期 ≥ 起始日期的列的「增減（元）」加總，再加上起始現金，應該等於「目前現金（元）」。對不上時，代表 Andy 在網站上記帳後還沒同步，或試算表被手動改過，請回報，不要自己修正。

## 7. 其他工作表

**月份統計**：每月每個渠道一列。欄位：月份（`YYYY-MM`）、渠道、支出（元）、收入（元）、提款（元）、存入（元）、筆數、月底現金（元）。月底現金只有現金那一列有值。

**設定**：兩欄式（項目、內容、說明），項目有：起始現金（元）、起始日期、設定更新時間、目前現金（元）、同步時間、資料格式版本、說明。

**選項**：欄位有種類、名稱、上層、圖示、狀態、更新時間。
- 種類是 `渠道`、`支出分類` 或 `收入分類`。
- 子分類的「上層」是主分類名稱。
- 狀態是 `使用中` 或 `已刪除`。分類被刪除後，已經記下的帳還是會保留原本的分類名稱。

**內建分類**（不會出現在「選項」裡）：
- 支出：餐飲（早餐、午餐、晚餐、飲料、點心、超商、外送）、交通（大眾運輸、計程車、加油、停車、高鐵火車）、日用品（超市、生活用品、美妝）、購物（服飾、網購、3C）、娛樂（電影、遊戲、訂閱、旅遊）、居家（房租、水電、電信、保險）、醫療（看診、藥品）、人情（轉帳給別人、禮金、請客）、其他（手續費、其他）。
- 收入：薪資（薪水、獎金）、投資（股利、利息）、其他收入（收到轉帳、退款、回饋、其他）。

**異動紀錄**：網站在多台裝置之間合併用，只增不改，同一個 ID 以「更新時間」最新的那列為準，狀態 `已刪除` 表示被刪除。要追查某筆被改過幾次時才需要讀。格式版本 1 的檔案沒有最後的「渠道」欄，視為現金。

## 8. 回報給 Andy 時

- 寫清楚資料讀到哪一天（「記帳明細」最後一列的日期），以及「設定」的同步時間。
- 待確認的項目要列出日期、金額、渠道、對象、備註，讓 Andy 可以馬上認出是哪一筆。
- 不要把手動記帳和匯出檔加在一起，算成兩倍的支出。
