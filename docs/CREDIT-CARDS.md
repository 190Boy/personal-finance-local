# v0.7.0：中信與凱基信用卡帳單

## 操作

1. 關閉舊網站／PWA 視窗後重開，確認右上角 v0.7.0。若仍舊版，到設定清除公開程式快取，再關閉全部視窗重開。
2. 「匯入」選「信用卡」，選凱基 Excel 或中信 CSV，填寫固定的信用卡帳戶代稱。同一銀行的同一帳單帳戶每次用相同名稱；不同人或不同帳單帳戶勿共用代稱。
3. 選檔並「本機讀取帳單」。需要時輸入 Excel 開啟密碼；本次提供的兩份檔案不需要密碼。CSV 自動識別 UTF-8／Big5。
4. 比對每筆消費日、入帳日、摘要、臺幣金額與交易種類。可逐筆修正種類。負數退款為支出減項，扣繳／繳款不算支出或收入；待核對用途不自動列生活支出。原始金額不因修改種類而改正負號。
5. 填帳單月份。中信 CSV 只有下載時間，不能用它猜帳單月份；凱基依最近結帳日建議月份，仍請核對。
6. 若要顯示首頁待繳：選已出帳，核對完整帳單總額（不是最低應繳）、結帳日、繳款截止日，填「本次結帳後已繳金額」及核對日，再勾選待繳確認。沒有繳款也須明確填 0，不會預設。帳單明細裡的前期扣繳已在帳單範圍內，不能再填入本次結帳後已繳。
7. 不確定待繳時，留在待確認或未出帳，不勾待繳確認，仍可同步明細。最後勾選資料同步同意，連接 Google 後點「確認並同步信用卡」。同步使用原本同一份個人試算表。
8. 首頁可見已確認帳單待繳與日期；交易明細可用「信用卡」類別篩選，重開後重新連接會載入。單純重新載入原匯入會排重。

## 檔案支援範圍

凱基已驗證欄位：月份、特店名稱、消費日期、消費金額、卡號末四碼、消費地、入帳日期、消費幣別。檔頭含月份帳單、最近結帳日、截止日、最低應繳及未標示用途的金額。該金額只是候選，不自動確認為完整帳單負債。

中信已驗證欄位：消費日、入帳起息日、摘要、幣別、消費地金額、外幣折算日、消費地、末四碼、新臺幣金額。CSV 未標銀行名稱，使用者必須自行選對來源；沒有可靠帳單總額、結帳日或截止日。

金額按明確的新臺幣欄位、以整數分保存；外幣資訊只作來源參考，不換匯。分期只保存本期入帳金額，不推算剩餘期數、本金、利息或未來負債。預借現金、回饋折抵、沖正等不確定用途保留待核對。此版不支援信用卡 PDF 解析；遇到不同欄名／多份表頭不猜測套用。每檔25 MiB，Excel沿用50,000列／256欄／20表／30秒與加密支援限制。

## 資料與會計界線

只新增一張「信用卡」工作表，21欄，以資料類型「帳單／明細」分開；所有月份共用。欄位定義在 cloud/credit-cards.mjs 的 CARD_HEADERS。銀行／股票原有工作表不改，匯入紀錄共用「匯入紀錄」並標類別信用卡。

首頁只取各銀行／帳戶最新已確認帳單月份、最近繳款核對日的帳單總額減結帳後已繳。舊月份不累加。新月份資訊缺漏則待確認；同月份未確認資訊會提示，仍保留上次確認範圍。更正同一月份須重新匯入、填完整資訊並用較新的核對日確認。金額衝突保留，不刪列。溢繳、負數帳單總額不猜成資產，請先保持待確認。

這是「核對日的已出帳待繳」，不是銀行即時信用卡總負債，不包含未出帳／未來分期。銀行卡費轉出與信用卡扣繳都保留為各自來源紀錄，沒有把繳款再當生活支出；跨來源自動配對尚未實作。首頁資產圓餅仍只比較正值銀行存款／股票，負債不混作資產扇區；完整淨資產仍未計算。

相同交易依銀行、帳戶代稱、日期、入帳日、摘要、臺幣金額及原幣資訊產生穩定識別碼；同檔合法相同交易用出現次數保留。跨檔重疊依識別碼與內容去重，分類內容衝突保留並標記。來源沒有唯一交易序號，無法保證辨識不同匯出中恰好同日同額同商店的不同交易；請核對原檔。同步沿用版本協調與原子批次，舊版或人工修改不遵循協調，仍可能留下重複。

## 隱私與安全

原始 Excel／CSV、Excel 密碼、卡號末四碼欄位不傳送、不寫入程式庫。未確認同步前只在裝置內讀取；確認後上傳結構化帳單與交易摘要、帳戶代稱、來源指紋、核對原因，這些仍屬敏感財務資料。交易摘要可能本身包含個資，請先核對。缺漏或錯誤來源列不悄悄刪除。

密碼送出即清空輸入，Excel Worker 完成／取消後終止；切換來源、清除、登出及離開頁面釋放程式持有參照。不能保證裝置或瀏覽器所有記憶體殘留已抹除。Token、密碼、原始檔與交易不存 localStorage、Cookie、IndexedDB 或 Service Worker；只快取227項固定公開程式資源。沒有新增第三方函式庫、後端解密或新的 OAuth 權限。

## 維護與測試

解析：pdf-parser/credit-cards.mjs；資料模型：cloud/credit-cards.mjs；介面：web/cards.mjs；同步：cloud/google.mjs、cloud/ui.mjs。銀行與股票原本流程保留。

執行 node --test tests/*.test.mjs；瀏覽器測試需 Node、Playwright 與 Chrome，執行 node tests/cards-browser.cjs（可用 CHROME_PATH 指定瀏覽器）；使用合成資料和模擬 Google API，不上傳實際來源檔。修改公開資源後執行 node tools/build-sw.cjs，整個 repo 由 GitHub Pages 發布。

本次 Windows Chrome 以實際兩份文件完成本機選檔與解析：凱基19筆、中信14筆／1筆扣繳；凱基候選總額與明細合計一致。該實測封鎖外部網路、沒有同步。實際內容、金額、卡號及檔案不納入公開測試。

真實 Google Sheets 寫入與 iPhone Safari／主畫面PWA／Android仍需使用者驗收：選檔、Big5中文、預覽欄位、密碼清空、手動月份、首次同步／重匯、首頁日期、重連歷史、登出清除、離線只讀程式。手機390px Chrome畫面測試不能替代iPhone實機。
