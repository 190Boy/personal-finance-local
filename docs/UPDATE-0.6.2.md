# v0.6.2：合併股票庫存、手機歷史交易與跨裝置排重

## 使用方式
更新後確認右上角 v0.6.2。交易明細頁上方顯示 Google 連接狀態；直接點「連接 Google 並載入」，已連接則點「重新載入交易」。不用跳到設定頁。Google 授權仍由使用者點擊觸發，不偷偷登入，也不保存 Token。

手機先顯示載入筆數與交易卡片，篩選預設收合。點「篩選交易」才展開類別／帳戶／日期／關鍵字。桌面保留完整表格。尚未連接、讀取中、雲端沒有交易、篩選無結果及讀取失敗會分別提示；失敗時已載入資料若有仍保留，不能把它當成重新載入成功。

v0.6.1 的截圖只能證明篩選欄位擋住首屏、連接提示不明，不能由截圖確認使用者是否完成 Google 授權或試算表內是否有交易。本版修正布局並提供直接載入與錯誤顯示，也避免股票格式／轉換錯誤連帶使有效銀行歷史全部消失。股票來源讀取失敗會顯示「部分來源未載入」，不宣稱歷史完整。

## 股票快照與庫存合併
正常使用只需「股票庫存」與「股票異動」，加上銀行／股票共用的「匯入紀錄」。不是每次匯入建立新工作表，只在固定工作表追加資料列。

「股票庫存」同頁包含：
- 每批一列「快照」標記，記錄報表時間、券商帳戶、預期持股筆數、總市值、內容指紋與匯入時間。
- 該批每檔一列「持股」，同時保留批次、代號、名稱、股數、收盤價、價格日期、市值及幣別。
- 零持股以「空庫存」標記表示，不沿用上次持股。這列也保留快照時間。
- 缺少對應快照的舊庫存以「缺快照」保留，提示待核對；不丟掉原紀錄。
這樣不多開一張快照表，仍可發現持股列缺漏、選取最新完整快照，以及排除同時間不同內容的衝突。

十七欄由 cloud/stock-layout.mjs 的 HOLDING_HEADERS 定義：
資料類型、快照ID、券商、帳戶代稱、報表產製時間、幣別、持股筆數、總市值分、內容指紋、匯入時間、證券代號、證券名稱、股數、收盤價、價格日期、市值分、持股幣別。
「總市值分」是批次總數，不得逐持股列累加；首頁驗證後只取該批一次。市值分／總市值分單位為分；收盤價單位仍為元。

下次連接、重新載入或股票儲存時，已知的舊九欄快照＋八欄庫存會以單次原子批次轉換為同張「股票庫存」並隱藏舊「股票快照」。舊快照不刪除，作遷移追溯；新資料不再寫入舊頁，也不新增另一張備份頁。銀行資料與共用匯入紀錄不刪除。未知欄位不覆寫，會提示失敗；有效銀行歷史仍可顯示。

## 排重與寫入協調
沿用既有穩定交易 ID，不靠檔名或寫入時間認交易：
- 每次寫入前重新讀取雲端 ID。
- 相同 ID、相同財務內容略過，不重複追加。
- 相同 ID、不同財務內容保留。銀行列標示 CLOUD_ID_CONFLICT、餘額待核對；畫面顯示中文衝突提示，不自行猜哪筆正確。
- 不同 ID、同日同額或不確定的候選不自動刪除。銀行待核對交易照常儲存。
- 同檔／同快照的既有批次 ID 與紀錄依然保留，斷線重試會先查成功紀錄。

新增不需要授權後端的試算表樂觀協調：
1. 新版客戶端先讀個人試算表內的 fw2 版本標記，再讀最新 ID 與資料。
2. 將「下一版的唯一 metadataId」和交易、匯入紀錄放進同一個 batchUpdate。
3. 兩台若讀到同一版本，只能一台成功建立同一個唯一標記；另一台整批失敗，重新讀最新版本與交易後重新比對，最多嘗試四次。
4. 回應遺失時先查匯入紀錄，避免已成功又重寫。重試耗盡會提示使用者稍後再試，預覽保留。

這是本程式依 Sheets metadata ID 唯一性與原子批次組合的協調機制，不是宣稱 Sheets 提供完整資料庫交易 API。測試涵蓋兩個獨立 GoogleStore 同時匯入不同重疊檔案，以及同一快照不同檔案。財務資料仍只在每位使用者自己的試算表，不新增共同財務資料庫或服務後端。

條件與限制：
- 所有裝置都要更新到此版並關閉舊頁面。舊版、其他程式或手動改表不會遵守版本協調，不能保證其併發寫入也被阻止。
- 同一實際帳戶繼續使用相同帳戶代稱；尚未實作帳戶改名／內部 accountId 遷移，不擅自合併不同代稱。
- 版本標記不能自動刪除或重設，否則舊的在途寫入可能重新成功。協調標記只存版本號，不存財務內容或密碼。
- Sheets metadata 有容量限制。本程式在試算表層級標記接近 28,000 字元時停止新同步並提示維護，保留預覽與原資料；不自動清理標記或改用不安全的寫入方式。既有每批標記也占容量，後續應另做受控維護或協調服務方案。
- 真實 Google API 的雙裝置競態與 iPhone Safari 尚未實機驗收；不能把模擬測試描述成實機保證。

官方依據：
- metadataId 必須唯一、metadata 容量限制：https://developers.google.com/workspace/sheets/api/guides/metadata
- 同批請求一起成功或失敗：https://developers.google.com/workspace/sheets/api/guides/batchupdate

## 隱私與快取
原始 PDF、密碼與 Google Token 的處理不變。沒有上傳銀行原始文件或密碼到新服務。歷史交易、卡片、帳號狀態與篩選資料只在記憶體，登出與離開清除；SW 只快取固定公開程式，包含新合併格式／排重模組。股票仍依報表價格日期顯示，非即時行情。
