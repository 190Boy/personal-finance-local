# v0.3.3 玉山三行表頭與跨行交易修正

支援本次回報的玉山「交易明細查詢下載」版型：三行表頭的提／存、日期／摘要與金額／時間分行。依表頭座標定位，不把提款與存款方向互換，也不從餘額反推金額。手續費另存 feeCents、CSV fee；非零或無法讀取的手續費須人工確認是否包含於提款額，該筆不能自動通過餘額核對。未定位的金額為未知，不再顯示 0.00；不對欄位不完整的列產生假重複候選。

重新開啟網站確認 v0.3.3，清除本次資料後選玉山、自動定位，依 PDF 日期實際排列選原始順序（此次回報為由新到舊），再選檔並輸入密碼。起始餘額必須填最早交易之前的餘額；未知可留空，此時最早一筆無法完整核對。逐筆核對筆數、日期、時間、摘要、提款、存入、餘額及獨立手續費。尚未使用真實 PDF 驗收，不能將合成測試視為銀行樣本通過。

此次來源只採用欄名與版型結構；交接文件與測試不包含使用者帳號、時間戳或實際交易資料。所有 PDF／密碼仍在瀏覽器記憶體內處理。

測試：node --test tests/parser.test.mjs tests/esun-layout.test.mjs tests/sw.test.mjs tests/geometry.test.mjs。跨行玉山測試資料全部虛構，涵蓋重複表頭、無重複表頭繼承、座標平移縮放、缺餘額、錯誤順序、零／非零／無效手續費與未定位金額。實際 iPhone Safari／PWA 與 Android 未在本環境驗證。

本次結果：37 項單元測試通過（其中 9 項為新玉山跨行座標案例）；Windows Chrome 15 項既有加密 PDF 回歸與 8 項 PWA 檢查通過。新玉山版型尚未取得完整 PDF，跨行案例為座標合成測試，不能宣稱已完成真實 PDF 端到端驗收。
