# v0.6.0 股票匯入、個人試算表與首頁占比

## 操作
1. 開啟工具，確認右上角 v0.6.0。首頁點「匯入股票 PDF」，或從銀行匯入頁進入股票入口。
2. B 選「證券存摺庫存資料」；C 可選「證券存摺登摺資料」。目前針對中國信託證券／集保這兩種下載版型。兩份請用同一帳戶、同一產製時間。
3. 填券商帳戶代稱（每次保持同名），輸入 PDF 密碼，確認為新臺幣一般庫存，再點本機解密。
4. 比對每檔代號、名稱、股數、收盤價、價格日期、市值。C 的提出／存入／餘額都是股數，不是交易現金。
5. 檢查股數連續性與庫存交叉核對。欄位不符、帳號不同、未知異動、非一般庫存、未知旋轉文字或數量不符會停用儲存。
6. 在設定連接 Google，回來勾選人工確認，點「確認並同步股票到雲端」。股票不套用銀行自動儲存開關。
7. 回首頁查看股票報表市值及資產占比。重新登入或重新載入雲端會讀回股票。匯出 JSON 是可選的本機核對檔，請自行保管。

只提供 B 時，可以人工確認後儲存經市值算術檢查的快照；畫面明確標示沒有異動歷史核對。C 必須與 B 一起使用。沒有期初股數時不宣稱完整歷史驗收。異動保留原始由新到舊順序，反向逐檔核對；不按日期猜測同日先後。

## 同一份 Google 試算表
沿用既有 drive.file 權限與資料庫識別，不新增 OAuth scope，不另建財務資料庫。建立以下四頁，欄名與順序由 cloud/stocks.mjs 的 STOCK_SCHEMAS 定義：
- 股票快照：快照 ID、券商、帳戶代稱、產製時間、幣別、筆數、總市值（分）、內容指紋、匯入時間。
- 股票庫存：快照 ID、證券代號、名稱、股數、幣別、收盤價、價格日期、市值（分）。
- 股票異動：異動指紋、券商、帳戶代稱、日期、代號、名稱、摘要、提出股數、存入股數、結存股數。
- 股票匯入紀錄：匯入指紋、券商、帳戶代稱、寫入時間、兩檔 SHA-256、核對範圍。

股票資料、匯入紀錄與批次標記以同一個 Sheets batchUpdate 原子寫入；字串使用 stringValue，不當成公式。API 失敗保留預覽，可重試；同一匯入、同一快照不重複加入，異動依股數／日期／代號等語意指紋及同檔出現次序去重。並行相同快照用 metadata ID 阻擋，衝突可重試。不同內容的同時點快照保留衝突並排除合計，不自動猜哪份正確。

每個券商／帳戶只取最新的完整快照，整份替換概念而非逐股票取最大日期；不再持有的證券不沿用舊庫存。零持股快照亦有快照表列。舊檔不蓋掉新快照；快照列數、市值與庫存不符時先排除。不要自行刪除快照／庫存關聯列或改欄名。相同真實帳戶使用不同代稱仍會被視為不同帳戶，請保持一致。

## 首頁
股票採 PDF 報表的收盤價與市值，顯示價格日期及報表產製時間，非即時行情。圓餅圖是「已載入正值資產占比」：可核對銀行存款＋最新完整股票快照。負值、待核對、缺少資料的來源不畫扇形；圖旁明示涵蓋範圍。信用卡與淨資產仍未計算，不將部分資產合計稱為淨資產。登出清空首頁雲端摘要。

文件未提供成交價、成本、費用與稅，不計算成本、報酬率或損益，不推估股票買賣的銀行現金流。買賣股數不列生活支出；尚未做跨銀行現金對帳、自動行情、信用／融資融券、借券、外幣及股利等未知摘要的自動處理。

## 本機與隱私
原始 PDF 與密碼僅在裝置記憶體；重用自託管 PDF.js 及專屬 Worker，處理完成銷毀工作。送出立即清空密碼輸入，finally 釋放密碼變數；頁面隱藏亦清空輸入。清除／登出／離開釋放預覽、檔案與下載 URL。無法保證裝置或瀏覽器所有記憶體殘留清除。

證券原始帳號只作本機報表配對，存於結果物件的 WeakMap 關聯；不進預覽匯出、Sheets、localStorage 或日誌。只有符合本報表帳號及產製時間的完整或被頁界裁切的集保浮水印文字可略過；其他未定位文字會阻擋儲存。實際交易／證券名稱僅顯示本機，人工同意後才送自己的 Google Sheets。

SW 僅快取固定公開程式，包含新增股票模組；不快取 PDF、密碼、Token 或交易。tools/build-sw.cjs 已納入 cloud 目錄及股票路由，後續修改程式後重新執行建置並提交 sw.js。移除舊清單中不存在的圖示路徑，避免整批離線安裝失敗；未更改圖示設計。
