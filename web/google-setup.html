Google 連接與資料說明

用戶只需登入自己的 Google 帳號

網站已設定共用 OAuth 用戶端。到「設定」點「連接 Google」，選擇你的帳號並授權即可；不用建立 Google Cloud 專案或填寫 Client ID。每位用戶的試算表保存在各自的 Drive。

目前仍為測試模式時，只有網站管理者加入測試名單的 Google 帳號可使用。公開使用前由管理者完成 Google 發布設定。

網站管理者的一次性設定

  1. 在 Google Cloud Console 建立或選擇你自己的專案。
  2. 到「API 和服務 → 程式庫」，啟用 Google Drive API 及 Google Sheets API。
  3. 到「Google Auth Platform」設定 Branding 與 Audience。個人測試可使用 External／Testing，將你登入用的 Google 帳號加入 Test users。應用程式名稱可填「我的理財」。
  4. Data Access 加入唯一需要的範圍：https://www.googleapis.com/auth/drive.file。這允許本工具存取它建立的檔案。
  5. 到 Clients 建立 OAuth client，類型選 Web application。Authorized JavaScript origins 填 https://190boy.github.io，不要加 /personal-finance-local/web/ 路徑。這個版本使用彈出視窗，不需要設定 Redirect URI。
  6. 將以 .apps.googleusercontent.com 結尾的公開 Client ID 設定在 Repo 的 cloud/config.mjs 並部署。一般用戶不需設定。Client Secret 不放入前端或 Repo，本流程也不需要 API Key。設定剛改完時可能需等待 Google 生效。
  7. 在 Google 視窗選擇你的帳號並同意權限。回到網站後會建立或開啟「我的理財紀錄」。若 Safari 阻擋視窗，允許本站彈出視窗；主畫面模式無法登入時，請先用 Safari 開啟本站測試。

官方參考：Google Token 授權流程、OAuth 用戶端設定、Drive 檔案權限。

日常使用

  1. 重新開啟網站後，到設定連接 Google。
  2. 匯入銀行檔案並填固定的帳戶代稱。同一銀行若有多個帳戶，請分別取不同名稱；不用輸入完整帳號。
  3. 解析完成後會依「自動儲存」選項寫入試算表，也可在交易明細按「儲存本次匯入」。尚未連接或同步失敗時預覽仍保留。
  4. 「銀行存款」頁保存兩家銀行的交易；「銀行」「帳戶代稱」欄位區分來源。「匯入紀錄」頁記錄批次與筆數。未來其他類別使用獨立工作表，目前沒有信用卡／股票匯入器。
  5. 首頁加總各帳戶最新日期／時間的可核對餘額。舊月份匯入不會蓋掉較新的餘額。無法確認先後順序或餘額異常的帳戶會列出提示，不冒充完整合計。這不是即時銀行餘額。

請保留系統欄名及欄位順序。可以使用 Google Sheets 的篩選器查看銀行與帳戶。重複檔案會跳過；重疊明細以交易指紋去重。不同裝置同時匯入重疊但不同檔案，仍可能留下相同 ID 的列；首頁會按 ID 去重，建議依序匯入。

資料與隱私

應用程式在瀏覽器解密原始檔。開啟密碼與原始 PDF／Excel 不傳給 Google。你啟用同步後，解析出的日期、摘要、金額、餘額、銀行、帳戶代稱、來源指紋與待核對原因會寫進你自己的 Google 試算表。摘要仍可能包含個人資料。

本工具沒有開發者資料庫。OAuth Token 與載入的交易只在本次頁面記憶體中，不寫 localStorage、Cookie 或 Service Worker 快取；公開 Client ID 由網站統一設定，不使用本機儲存。Google 官方授權元件僅於設定連接時載入。

中斷連接或關閉頁面會清除本次授權；雲端紀錄會保留。要刪除雲端資料，請自行在 Drive 刪除試算表；可到 Google 帳戶連線設定撤銷授權。Drive 的分享設定由你自行管理，本工具不公開或分享檔案。

應用程式問題可到 GitHub Issues 回報，請勿附上密碼、完整交易內容或銀行檔案。
