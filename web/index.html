銀行資料匯入

實驗版／待真實樣本驗收

這是解析測試工具，沒有入帳功能。銀行格式、字型或跨頁方式不同時，可能需要調整欄位位置。

檔案上限 25 MiB；中信 PDF 上限 200 頁、90 秒；玉山 Excel 上限 50,000 筆記錄。沒有期初餘額時，最早一筆會標示「無起始餘額」，不能算完整餘額核對通過。

欄位位置設定（自動定位失敗時使用）

填各欄中心距頁面左緣的百分比（0–100），所有必要欄位均須填寫。時間與備註可留空。數值由實際 PDF 的欄位位置決定，不能用餘額倒推金額。

玉山 Excel 欄位對應

接受 .xls／.xlsx。讀取與預覽只在本機；手續費獨立處理，不自動併入提款。含非零手續費時先保留待核對。

先完成玉山 Excel／中信 PDF 的實際欄位與餘額驗收，再加入 Google OAuth 與各使用者自己的 Drive／Sheets。此版本沒有登入或 Token，iPhone Safari 與主畫面登入流程尚未測試。


本機資料管理
公開程式快取只包含應用程式、圖示、PDF.js 與字型。清除快取不會替你刪除已匯出的下載檔。




資料與隱私


PDF.js、Worker、中文字碼表與字型檔均由本專案提供。頁面不載入分析、追蹤或第三方腳本；PDF 以本機位元組傳入，不提供上傳或雲端備援。網路只允許取得同站靜態程式資源。


密碼送出後立即清空；每次完成會銷毀 PDF.js 工作與 Worker。預覽保留至你清除或離開頁面，匯出檔由你自行保管。我們只能釋放程式持有的參照，無法保證瀏覽器、作業系統或受入侵裝置的所有記憶體殘留都被清除。


Windows Chrome 自動測試與 iPhone Safari 實機測試分別記錄，不能用手機畫面模擬替代 iPhone 實機驗收。開發者工具的 Network 可檢查載入與解析期間沒有 PDF／密碼請求。
